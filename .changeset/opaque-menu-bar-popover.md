The menu bar popover now has a solid background, so server rows stay readable no matter what window or wallpaper sits behind it. The filter and sort controls at the top are solid too, so rows scrolling beneath them no longer show through. The popover also follows your system Light or Dark setting; before, it followed the menu bar, which macOS tints to match the wallpaper, so a Dark Mode user on a bright wallpaper got a light popover.
